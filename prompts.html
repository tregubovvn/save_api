Prompts API — режимы редактора

Выбор промпта переключает режим работы редактора. Окно режимов: выпадающий список, просмотр промпта выбранного режима, добавление своих режимов и сохранение всех режимов в один Gist.

Как это работает

  1. Режим = промпт. Название режима — заголовок первого уровня (# Название) в тексте промпта.
  2. Два базовых режима доступны всегда: их текст берётся из их собственных публичных Gist'ов.
  3. Без GitHub Token доступны только эти два режима; свои режимы хранятся в одном Gist и требуют токен.
  4. «Применить режим» переключает редактор, «Изменить» правит промпт, «Сохранить в Gist» записывает все режимы в один файл.
